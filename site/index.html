One system

What's in the box

Every Groth16 limitation, removed — without giving up the 192-byte proof.

🌍

Universal setup

One updatable KZG ceremony covers every circuit of a given size. No per-circuit trusted setup.

🛡️

Simulation-extractable

Every proof is SE by default via ROM hash blinding — near-zero overhead, no config.

📦

N-to-1 aggregation

Compress N proofs into one. Verify a batch of 32 in a single multi-pairing — ~32× cheaper.

♾️

Folding / IVC

ProtoStar accumulation with a full relaxed-R1CS decision predicate. Fold, verify once.

⚛️

Post-quantum path

Binius, Plonky3 & Hybrid inner provers — quantum-resistant proofs today, classical proof size.

⛓️

Auto Solidity verifier

Generate a ~250k-gas on-chain verifier from any VK using EIP-196/197 precompiles.

🧩

Plonkish gates

Custom gates (Poseidon, EC add), lookup tables, and Plonkish-to-R1CS conversion.

🗜️

VK compression

O(n) → O(1) verifying keys via KZG. Built for zkEVMs with thousands of public inputs.

🌊

Streaming prover

Bounded-memory MSMs in chunks — prove circuits too large to fit in RAM.
